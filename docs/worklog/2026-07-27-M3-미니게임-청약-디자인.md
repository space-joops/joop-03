# 2026-07-27 · M3 디자인 납품 (지상 미니게임 + 발사체 청약 + 쓰레기 스프라이트·조이스틱)

## 무엇을 했나

[M2 납품](./2026-07-27-M2-온보딩-디자인과-줍스-캐릭터.md)에 이어 마일스톤 단위 납품 3탄. [로드맵](../product/roadmap.md)의 M3(E3 지상 미니게임 + E4 발사체 청약)에 필요한 것 전부:

1. **우주 쓰레기 스프라이트 세트** — 6종(캔·볼트·너트·태양전지판 파편·구조재·회로기판) 64×64 시트(`public/game/debris-sheet.png`, 12KB) + 메타 JSON(점수·사이즈 클래스 S/M/L·회전 규칙). 인벤토리 C 두 번째 항목.
2. **5원 반투명 조이스틱 수치 명세** — 링 4(r18/32/46/60) + 노브(r14). 파일이 아니라 명세로 납품(아래 결정).
3. **M3 화면 시안 3종** — [mockups/minigame-subscription.html](../design/mockups/minigame-subscription.html): ① 지상 미니게임(장면+HUD+조이스틱) ② 발사체 청약 리스트 ③ 선별 결과.
4. **[M3 핸드오프 가이드](../design/handoff-m3.md)** — 장면·HUD 명세, 스프라이트·조이스틱 계약, 청약 카드 상태 4종, i18n 키.

## 결정한 것들 (문제 → 선택지 → 이유)

### 1. 조이스틱은 파일이 아니라 수치 명세
- **선택지**: (a) SVG/PNG 에셋 (b) 수치 명세(코드 드로잉).
- **결정**: (b). 조이스틱은 터치 지점에 등장해 드래그 길이·단계에 따라 매 프레임 변하는 **동적 UI**라, 이미지보다 원·선 5개의 파라미터(반경·색·불투명도·클램프)가 정확한 납품물이다. 인벤토리의 "지구본·스파크라인은 수치 명세" 원칙과 동일 문법. 시안 ①에 시각 레퍼런스를 그려 넣었다.

### 2. 쓰레기는 종당 1프레임 + 코드 회전
- 캐릭터(상태 연기가 필요 → 프레임)와 달리 쓰레기는 강체 회전만 있으면 충분하다. 프레임을 늘리는 대신 **메타 JSON에 스핀 범위(-30~+30 deg/s)와 사이즈 클래스 스케일**을 정의해 시트를 12KB로 억제했다. 외곽선 `#5c6b5e` 2px는 지상(어두운 하늘)과 아케이드(우주) 양쪽 배경에서 실루엣을 보장한다 — M5에서 같은 시트를 재사용한다.
- 종 선정: 실제 우주 쓰레기 구성(페인트 조각·로켓 파편·위성 부품)에서 게임적으로 읽히는 6종. 음료캔은 사실성보다 **"쓰레기"라는 즉각 인지**를 위한 상징(레트로 유머).

### 3. 미니게임 장면: 원근 그리드 지평선
- 지상감을 사진 배경 없이 만들기 위해 **지평선(화면 66%) + 소실점 원근 그리드**를 채택 — 카세트퓨처리즘의 레이더/벡터 스캔 미감과 일치하고, Canvas로 선 몇 개면 그려진다(에셋 0KB). 발사장 실루엣(타워+경고등)이 "여기서 발사된다"는 목표를 장면 안에 심는다.
- 연료(분사가스) 게이지는 **앰버**로 — 그린(XP/수거)과 계기 색을 분리해 HUD 스캔이 빨라진다. FR-7.6(분사가스 소진 = 종료)의 시각 언어를 지상에서 미리 학습시킨다.

### 4. 청약: 실 발사체 데이터 + 상태 칩 4종
- FR-4.1의 "실 우주 발사체 리스트"를 존중해 시안 더미도 실제 기체(누리·Falcon 9·H3·Ariane 6)와 실제 발사장으로 구성, 현지 시간대 병기. 상태는 칩 4종(모집 중=앰버 / 마감=muted / 선별 대기=시안 / 탑승 확정=success)으로 통일 — 색만으로 상태 스캔이 가능하다.
- 선별 결과 화면은 확정 히어로 + **미선정 안내 패널을 같은 화면에** 배치해 FR-4.3(결과 확인)의 양쪽 상태를 한 문법으로 처리.

### 5. 규칙 자가 교정
- 시안 초안에서 "탑승 확정!"(한글)에 display 폰트를 썼다가 **토큰 규칙(디스플레이 폰트는 숫자·라틴 전용) 위반**을 발견하고 body 800으로 교정했다. 숫자인 D-day(`D-18`)만 display를 유지. 가이드 §6에 명문화.

## 검증

- 쓰레기 6종 128px 확대 그리드 전수 검수(실루엣·색 대비).
- 시안 3프레임 시트 스크린샷 검수 — 프레임 라벨 폭 때문에 3번 프레임이 잘리는 문제 발견·수정(라벨 max-width 393px).
- 용량: debris-sheet 12KB + 메타, 시안 스크린샷 164KB.

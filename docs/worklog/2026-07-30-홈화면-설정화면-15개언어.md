# 2026-07-30 — 홈 화면 개편 · 설정 화면 신설 · 15개 언어 지원 (v0.17.0)

## 무엇을 왜 했나

요구 7건:

1. 홈 화면 상단의 장식용 시계(G.S.T.) 제거
2. **설정 화면**을 새로 만들어 언어를 15개국어(+자동 감지, 기본값)로 설정
3. **기지국 설정** — 음영 지역 계산과 연동
4. **지구로 복귀** 버튼도 설정 화면으로 이동
5. 화면 곳곳의 상단 "홈" 버튼 제거
6. 첫 화면에 내줍스/인벤토리/우주지도/설정 하단 버튼 메뉴 신설
7. 다른 화면에도 가능한 곳엔 홈 버튼 포함 하단 버튼 메뉴 생성

사용자 결정 3건:
- **기지국 설정**: 코드베이스에 실제 "기지국"이라는 별도 개념이 없다는 걸 확인한 뒤(내 줍스의 궤도/음영 상태가 이미 우주지도 화면에 표시되고, 음영 계산 파라미터는 관리자 전용 설정으로만 존재), 이번 단계에서는 **음영 지역 계산과 실제로 연동하지 않고** 세계 주요 도시를 검색·선택하는 UI만 먼저 만들기로 함. 연동은 차후 작업.
- **하단 버튼 메뉴**: 게임 전체 화면이 아니라 **핵심 3화면(첫 화면 / 내 줍스 허브 / 설정)에만** 적용. 우주지도·인벤토리·훈련·발사·랭킹 화면은 이번 범위 밖.
- **15개 언어 번역**: 전문 번역 검수 없이 **AI가 직접 번역**(아랍어 RTL 레이아웃 포함)해서 채우기로 함.

## 1. 시계 제거

`components/status-bar.tsx`는 상단 안전영역 패딩 + 시계(G.S.T.) + 신호/배터리 장식 글리프를 한 컴포넌트가 겸하고 있었다. 시계 관련 `useState`/`useEffect`(1초 setInterval)만 걷어내고, 패딩과 좌우 장식 글리프(`▚▚▚`, `▮▮▮▯`)는 그대로 뒀다 — 순수 장식이라 훅이 필요 없어져 `"use client"`도 함께 제거했다.

## 2. i18n을 2개 → 15개 언어로 확장

`lib/i18n/config.ts`의 `locales`를 `en/ko` 2개에서 `en, ko, fr, it, de, es, zh, ja, ru, pt, id, th, vi, hi, ar` 15개로 확장했다. `proxy.ts`의 로케일 감지 로직(`getLocale`)은 원래부터 `locales` 배열을 순회하는 범용 코드였어서 **로직 변경 없이 그대로 15개를 지원**한다 — 쿠키 우선 → `Accept-Language` 파싱 → `en` 폴백 순서라, 요구사항의 "자동 감지가 기본값"은 사실상 기존 구조가 이미 충족하고 있었다.

번역 딕셔너리(`lib/i18n/dictionaries/*.json`, 키 약 100여 개)는 `en.json`을 기준 스키마로 13개 신규 로케일 파일을 새로 작성했다. 285줄짜리 파일을 13개 언어로 옮기는 작업이라 4개의 서브에이전트에 언어군을 나눠 병렬로 맡겼다(fr/it/de/es · zh/ja/ru · pt/id/vi · th/hi/ar). 각 에이전트에게 다음을 강제했다:
- 키 구조는 절대 바꾸지 않을 것
- `{name}`, `{cost}` 같은 중괄호 플레이스홀더는 번역하지 말 것
- "JOOPS" 브랜드명은 유지할 것
- 작업 후 `JSON.parse` + 원본과의 키 diff로 자체 검증할 것

받은 뒤 다시 한번 전체 15개 파일에 대해 en.json과의 재귀적 키 구조 비교 + 플레이스홀더 보존 여부를 스크립트로 직접 재검증했다(누락/추가 0건).

**아랍어 RTL**: `app/[lang]/layout.tsx`의 `<html>`에 `dir={isRtlLocale(lang) ? "rtl" : "ltr"}`을 추가했다(`lib/i18n/config.ts`에 `rtlLocales`/`isRtlLocale` 신설). 지금은 `ar` 하나뿐이라 배열로 만들어 확장 여지를 뒀다.

## 3. 설정 화면 신설

새 라우트 `/[lang]/settings`(`app/[lang]/settings/page.tsx`) + `components/settings-view.tsx`. 언어·기지국·지구 복귀 세 섹션을 한 화면에 모았다:

- **언어**: `components/language-setting.tsx` 신설. "자동(기본값)" + 15개 언어를 세로 목록으로 보여준다. 특정 언어를 고르면 기존 `language-switcher.tsx`의 쿠키 저장 + 경로 세그먼트 교체 로직을 그대로 재사용하고, "자동"을 고르면 `NEXT_LOCALE` 쿠키를 지우고 `/`로 이동해 `proxy.ts`가 `Accept-Language`로 다시 감지하게 한다. 홈 화면 헤더에 있던 기존 `LanguageSwitcher`(en/ko 2버튼)는 설정 화면으로 완전히 대체됐으므로 삭제했다.
- **기지국**: 아래 4번 참고.
- **지구 복귀**: `mine.status === "orbit"`일 때만 기존 `components/return-earth-button.tsx`를 그대로 렌더(로직 변경 없이 위치만 이동). 원래 "내 줍스" 허브와 "우주지도" 두 곳에 중복으로 있던 걸 설정 화면 한 곳으로 합쳤다.

설정 화면은 온보딩 전(줍스 미분양) 사용자도 들어올 수 있어야 해서 `getMyJoop()`이 `null`이어도 리다이렉트하지 않는다 — 지구 복귀 섹션만 조건부로 숨긴다.

## 4. 기지국 = 세계 주요 도시 검색 (연동은 TODO)

`lib/cities.ts`에 세계 주요 도시 약 100개(이름/국가/위경도)를 정적 데이터로 만들고, `lib/base-station-prefs.ts`(`lib/sound-prefs.ts`의 localStorage + `useSyncExternalStore` + 커스텀 이벤트 관용구를 그대로 따름)로 선택값을 저장한다. `components/base-station-setting.tsx`는 검색어 입력 → 이름/국가 부분일치 필터 → 선택 UI다.

화면에 "추후 음영 지역 계산과 연동될 예정이에요" 안내 문구를 명시했다 — **지금은 저장만 하고 `lib/orbit.ts`/`lib/space.ts`의 실제 음영 판정에는 아직 연결하지 않는다**(사용자 확인 사항, 아래 TODO 참고).

## 5. 상단 홈 버튼 제거 + 하단 네비게이션

8개 화면(`joop`, `joop/map`, `joop/inventory`, `joop/train`, `joop/launch`, `joop/launch/replay`, `launch`, `rankings`)에 똑같이 복붙되어 있던 상단 `<header>`의 "← 홈" 링크(`dict.joop.back`, 실제로는 대부분 "내 줍스로 돌아가기"였다)를 전부 제거했다. 재사용 가능한 공통 헤더 컴포넌트가 애초에 없어서 파일마다 개별 편집했다.

신규 `components/bottom-nav.tsx`(홈/내줍스/인벤토리/우주지도/설정, 인라인 SVG 아이콘)를 만들어 **핵심 3화면에만** 붙였다:
- 첫 화면: 내줍스/인벤토리/우주지도/설정 4개(자기 자신인 홈은 제외)
- 내 줍스 허브 · 설정 화면: 홈 포함 5개

나머지 5개 화면(우주지도/인벤토리/훈련/발사/랭킹)은 상단 링크만 사라지고 하단 네비게이션은 붙지 않는다 — 브라우저/기기 뒤로가기나 핵심 화면 경유로만 복귀 가능하다. 사용자가 명시적으로 승인한 범위 축소다.

## 6. 부수 발견 — 지역명(GeoName) 타입 버그

로케일을 15개로 늘리고 `next build`를 돌리자 `components/orbit-track-map.tsx:344`에서 타입 에러가 났다. "현재 상공" 국가/해역 이름을 담은 `lib/geo-regions.ts`의 `GeoName` 타입이 `{ ko: string; en: string }`뿐이라, `regionAt(...)[lang]`처럼 15개 로케일 중 하나로 바로 인덱싱하면 `fr` 같은 나머지 13개 키가 없어서 타입이 깨졌다. 50여 개 국가 + 5개 해역 이름을 15개 언어로 전부 옮기는 건 이번 요구사항 밖이라, `regionName(geo, lang)` 헬퍼를 추가해 **ko가 아니면 en으로 폴백**하도록 처리했다(앱의 기본 폴백 언어 방침과 동일).

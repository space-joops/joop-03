# M6 디자인 산출물(PR #19) 공통 UI 적용 — 토큰 v1.0 · 토스트 · 다이얼로그 · 버튼 · 탭바

## 문제 상황

디자인 에이전트가 스택 PR(#9→#10→#14→#17→#18→#19)의 마지막인 **PR #19**로 M6 시안과 함께 **전 화면 공통 UI 가이드**(`docs/design/handoff-m6.md` §4)를 납품했다. 그런데:

- PR #19의 본편(인벤토리·합성 화면)은 **M6 범위**인데, main은 M1~M3까지만 구현된 상태. M4(지도)·M5(아케이드)도 미개발이라 시안 대부분이 아직 붙을 곳이 없다.
- main에는 공통 UI가 전무했다 — 에러는 인라인 `<p>`, 버튼 스타일은 7곳 복붙, 청약(되돌릴 수 없는 액션)은 확인 없이 즉시 실행.
- 디자인 스택은 **토큰 v1.0**(primary `#39ff14`, 그린톤 surface) 기준인데 main 토큰은 구버전(`#35e07a`, 블루톤)이라, 가이드 스펙을 그대로 구현하면 색이 어긋난다. 스펙이 참조하는 `--color-primary-dim`·`--color-surface-raised`·`--ease-console` 등은 main에 아예 없었다.

## 선택지와 결정

1. **적용 범위** — (a) 디자인 스택 전체를 병합 (b) 현재 개발 범위에 적용 가능한 부분만 반영.
   → **(b)**. 스택은 main과 분기점이 오래돼(충돌 후보 13파일) 병합은 별도 트랙이고, M4~M6 화면 없이 시안을 다 받을 수도 없다. 공통 UI 4종 + 토큰 + 에셋만 개발 코드에 반영했다(에셋 납품 PR과 코드 적용 PR을 분리한 #11→#12 선례).
2. **토큰** — (a) v1.0 값으로 교체 (b) 현재 값 유지. → **(a) (사용자 확정)**. "이름 고정, 값만 변경" 관행 그대로라 컴포넌트 수정 없이 전 화면이 확정 팔레트로 전환된다. 단 **`--color-grid`는 구값 유지**: v1.0 grid는 rgba(알파 포함)인데 Canvas 2곳(`orbital-canvas.tsx`, `ground-minigame.tsx`)이 `getComputedStyle`로 읽은 뒤 `globalAlpha`를 또 곱해 이중 알파로 그리드가 사실상 사라진다. Canvas 알파 정리와 함께 후속 교체.
3. **탭바** — (a) M4/M6까지 보류 (b) 지금 부분 구현. → **(b) (사용자 확정)**. 지도 탭은 현 궤도 대시보드(`/{lang}`)를 인터림 홈으로, 설정 탭은 신규 미니 설정 화면으로 연결하고, 인벤토리·랭킹 탭은 비활성(muted + opacity 40%) 처리했다. **비활성 탭은 가이드에 없는 인터림 상태**라 PR #19에 정식 스펙을 질의해 두었다. 가이드의 "미로그인 랜딩은 탭바 없음"은 그대로 — 첫 화면은 `myJoop` 보유 시에만 탭바를 렌더한다(서버 데이터 조건이라 layout 전역 렌더 대신 페이지별 명시 렌더 채택).
4. **토스트 API** — dict를 컨텍스트로 내릴지, 호출자가 번역된 문자열을 넘길지. → **후자**. 번역 JSON을 클라 번들에 넣지 않는 원칙(ADR-0001) 유지. 단일 슬롯(신규가 기존 대체), 성공·정보 3초/오류 5초, reduced-motion 즉시 표시.
5. **다이얼로그 적용처** — 가이드 규칙 "되돌릴 수 없는 액션만"에 따라 **청약(bookLaunch)** 앞에 확인 다이얼로그를 추가했다(청약은 취소 플로우가 없음). 대기리스트 등록·합성 같은 "얻는 행동"은 토스트.
6. **DB** — 변경 없음. M6 인벤토리를 실제로 만들 때는 수거물 종류별 기록(`debris_events`에 종류 컬럼 없음, 미니게임 결과는 아예 미기록), 아이템·레시피 테이블 등 스키마 작업이 필요하다 — 그때 신중히 별도 설계.

## 변경 요약

- **토큰**: `app/globals.css` v1.0 전면 교체 + 신규 토큰(`--color-primary-dim`, `--color-surface-raised`, `--page-pad-x`, `--ease-console`, `--glow-text` 등). `themeColor`(`app/[lang]/layout.tsx`)·`app/manifest.ts` `#05080a` 동기화. `docs/design/design-tokens.md` v1.0 사본으로 갱신.
- **신규 컴포넌트**: `components/toast.tsx`(Provider+useToast), `components/confirm-dialog.tsx`(코너 나사 4점), `components/button.tsx`(Button/ButtonLink, 스타일은 globals.css `.btn-console-*`), `components/tab-bar.tsx`(4탭, 인라인 SVG currentColor).
- **신규 화면**: `/{lang}/settings` — 언어 스위처(첫 화면 헤더에서 이전, 미로그인 랜딩엔 유지)와 버전 표시(구 `version-badge.tsx` 삭제·이전, 탭바와 우하단 겹침 해소).
- **적용**: 청약 확인 다이얼로그+토스트(`launch-list.tsx`), 대기리스트 성공 토스트(`onboarding-form.tsx`, `{error:"joined"}` 핵 제거), 버튼 7곳 공통화.
- **에셋**: `public/ui/`에 탭 아이콘 4종 + 아이템 아이콘 5종(32 그리드 고유색 — currentColor 규칙의 명문화된 예외) 랜딩. `docs/design/handoff-m6.md` 사본 랜딩.

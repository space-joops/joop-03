# 2026-07-27 · 디자인 1순위 발주 — 브랜드 · 토큰 · PWA 아이콘

디자인 브리프대로 **1순위 산출물**(코어 디자인 토큰 확정 + 브랜드 로고/심볼 + PWA 아이콘 세트)을 실제 에셋으로 만든 기록입니다. 이번 "발주"는 외부 사람 디자이너가 아니라 **서브 에이전트에게 생성 작업을 위임**하는 방식으로 진행했습니다.

## 왜 이렇게 했나

디자인 문서(브리프·토큰 초안·에셋 인벤토리·커밋 규칙)는 이미 갖춰져 있었습니다. 이번엔 그 문서를 근거로 **실제 파일**을 만들 차례라, 서브 에이전트에게 문서를 컨텍스트로 주고 1순위 에셋을 생성하게 했습니다. 에셋은 repo에 직접 커밋하는 규칙(`docs/design/README.md`)이라, 결과물이 곧바로 코드에 반영됩니다. 커밋·배포는 위임하지 않고 사람 검토(=이 세션)를 거쳐 처리했습니다.

## 무엇이 나왔나

**코어 디자인 토큰 확정** (`docs/design/design-tokens.md` 초안 → 확정, `app/globals.css` 반영)
- 변수 이름(`--color-bg/surface/fg/muted/primary/secondary/accent/danger/success/grid`)은 M1 컴포넌트가 참조하므로 그대로 두고 **값만 확정**.
- 확정 팔레트: bg `#05070f` · surface `#0f1826` · fg `#e4f2e9` · muted `#8a9e92` · primary(형광 그린) `#35e07a` · secondary(앰버) `#ffb23e` · accent(시안) `#38e0f0` · danger `#ff5c77` · success(라임) `#7ce64b` · grid `#1e5a46`.
- 뉴트럴 스케일, CRT 글로우(`--glow-*`), 타이포 스케일, 8pt 간격, 반경 토큰을 추가(기존 컴포넌트 무손상).
- 대비: 컴포넌트가 쓰는 조합을 WCAG로 점검해 AA 통과 확인(형광 버튼 위 다크 텍스트 등).

**브랜드 (SVG)** — 원본 `public/design-src/brand/`, 산출물 `public/brand/`
- `logo-wordmark.svg`(단색·currentColor), `logo-wordmark-phosphor.svg`(형광+글로우), `logo-symbol.svg`.
- 컨셉: 딥스페이스 콘솔 위, 궤도 링을 두른 **CRT 얼굴의 반려 청소 로봇**(형광 그린 눈 + 앰버 안테나 비컨).

**PWA 아이콘 세트** — 마스터 `public/design-src/icons/*.svg`
- `public/icon.svg`(임시본 교체), `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`(안전영역 준수), `app/apple-icon.png`(180). 전부 ≤23KB.
- 변환: `sharp`(devDep) + `scripts/generate-icons.mjs`(`npm run gen:icons`)로 마스터 SVG → PNG 자동 생성. `app/manifest.ts` icons 배열을 192/512/maskable로 갱신, `theme_color`/배경을 `#05070f`로 통일(`viewport.themeColor`도 동기화).

**보너스** — 첫 화면 UI 아이콘 SVG(`public/ui/icon-language.svg`, `arrow-up.svg`, `arrow-down.svg`).

## 검증

- `npm run lint` / `npm run build` 통과. `apple-icon.png`·`manifest.webmanifest` 라우트 정상 생성.
- 토큰 값만 바꿔 M1 컴포넌트가 자동 반영(변수 이름 고정). 배포 후 프로덕션 화면에서 시각 확인.

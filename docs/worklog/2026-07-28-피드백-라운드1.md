# 2026-07-28 — 실기기 피드백 라운드 1 (랭킹·발사·복귀·디자인·아케이드, v0.11.0)

## 배경

사용자가 실기기에서 전체 흐름을 플레이하고 피드백 10건을 줬다. 개별 버그 수정이 아니라
"첫 화면 → 발사 → 궤도 → 아케이드"의 체감 품질을 한 바퀴 올리는 라운드였다.

1. 첫 화면에서 내 랭킹 확인
2. 첫 화면이 한 화면에(하단 CTA까지) 들어가게
3. 랭킹 자세히 보기
4. 발사 화면 위쪽에 붙는 문제 + 내가 청약한 발사체가 발사되게
5. 지구로 복귀해서 처음부터 다시 발사 가능하게
6. PWA 아이콘·로고 — `design/m5-arcade` 브랜치 디자인 반영
7. 아케이드 롱프레스 시 복사 팝업 방어
8. 조이스틱 확대 + 분사량에 따른 화염 크기·색 변화
9. 우주 속도 표시
10. 사실감 있는 우주 배경

## 무엇을, 왜, 어떻게

### 1·2·3) 랭킹 — 내 순위·압축·자세히 보기

- **마이그레이션 없이** 해결했다. 주간 랭킹 뷰(`joop_03_rankings_weekly`)가 이미 `joop_id`를
  노출하고 anon 읽기가 가능해서, `lib/rankings.ts`에 `.eq("joop_id", id).maybeSingle()` 한 방인
  `getMyRanking()`만 추가하면 됐다. **스키마를 바꾸기 전에 기존 뷰가 뭘 노출하는지 먼저 확인할 것.**
- 첫 화면은 상위 5명만 보여주고, 내가 그 안에 없으면 목록 아래 "⋯" + 고정 행으로 내 순위를
  붙였다(액센트 테두리 + "나" 배지). 전체 목록은 신규 `/{lang}/rankings` 페이지(상위 100).
- "한 화면에" 요구는 390×780 기준 **오버플로 180px → 0px**까지 압축했다. 큰 순서대로:
  지구본 캔버스 `aspect-square → aspect-[7/5]`(가장 효과 큼), 게이지·랭킹 행 패딩 축소,
  캡션 두 줄을 한 줄로 병합, 누적 수거 숫자 `text-2xl → text-lg`. Playwright로
  `document.documentElement.scrollHeight - innerHeight`를 재면서 줄였다 — 감이 아니라 숫자로.

### 4) 발사 화면 — 세 번째 같은 버그

발사 캔버스가 화면 위쪽 ~150px로 쪼그라드는 원인은 **지상 훈련·아케이드에서 이미 두 번
고친 것과 완전히 같은 버그**였다: in-flow `<canvas className="h-full">`는 부모가 flex여도
고유 종횡비(기본 300×150)가 이겨서 늘어나지 않는다. 컨테이너를 `relative`로 두고 캔버스를
`absolute inset-0 block h-full w-full`로 띄우는 게 정답. **같은 실수 3회 — 캔버스를 컨테이너에
채울 땐 무조건 absolute 패턴을 쓰자.**

발사체는 `getMyConfirmedVehicle()`(bookings confirmed → vehicles 조회)로 실제 청약한 기체를
가져와 미션 행(기체명 · 제공사 · 발사장)으로 표시하고, 로켓도 코드 막대 대신 디자인 브랜치의
`rocket.svg`(64×160, 노즐 앵커 [32,152])로 그린다. 카운트다운 중엔 발사대 정경(타워·패드)을
정적으로 렌더한다.

### 5) 지구 복귀

신규 서버 액션 `returnToEarth()`. 컬럼 정리에 함정이 둘 있었다:

- 궤도 파라미터 5종이 **NOT NULL**이라 지우는 게 아니라 셋업 기본값으로 되돌려야 한다.
- `last_collected_at`을 **반드시 null로** — 안 지우면 지상에 머문 시간이 다음 발사 후
  "그동안 수거한 것"으로 소급 정산된다.
- confirmed 예약은 status 확장(마이그레이션 필요) 대신 **삭제** — 정원이 반환되고 같은 기체에
  재청약할 수 있다. XP·레벨·누적 수거량은 유지.
- 동시성은 기존 패턴 그대로: `.eq("status","orbit")` 조건부 갱신 + `.select()` 행 수 확인.

버튼은 2단 확인(첫 탭에 "정말 복귀할까요?"로 변신, 재탭 시 실행). 파괴적 액션에 모달 없이
확인을 넣는 저렴한 패턴.

### 6) PWA 아이콘·로고 (design/m5-arcade 반영)

`git show origin/design/m5-arcade:<path> > <path>`로 마스터 SVG·로고·UI 아이콘을 복사하고
`scripts/generate-icons.mjs`로 산출물을 재생성했다. 여기서 빌드가 깨졌는데 원인이 교묘하다:

> **Turbopack은 ICO 안에 임베드된 PNG가 RGBA일 것을 요구한다.** 새 favicon-master가 단순한
> 그림이라 sharp가 팔레트 PNG로 최적화해 버렸고, `Format error decoding Ico: The PNG is not
> in RGBA format!`으로 빌드가 실패했다. `.ensureAlpha().png({ palette: false })`로 강제했다.

스플래시 PNG 5종은 두 브랜치가 동일해서 손대지 않았다. 인앱 스플래시는 `logo-symbol.svg`를
쓰므로 로고 교체만으로 자동 갱신된다.

### 7~10) 아케이드

- **롱프레스 방어**: `.game-surface` CSS 유틸(`-webkit-touch-callout/user-select: none`) +
  `onContextMenu preventDefault`. 아케이드·지상 훈련 컨테이너 공통 적용.
- **조이스틱**: 반지름 `u*0.17` 이 두 곳에 중복돼 있어 `JOYSTICK_R = 0.24` 상수로 추출하며 확대.
- **화염**: 세기별 색 보간(저출력 시안 → 중간 앰버 → 풀출력 백열 코어) + 배기 파티클
  (핸드오프 m5 §3 명세: r5→11, 불투명도 .35→.08, 수명 600ms, 초당 12×세기, 상한 60).
  reduced-motion에선 파티클 생략.
- **속도 HUD**: `7.9 × |vel|/maxSpeed` km/s — 실제 LEO 궤도 속도(7.9km/s)를 게임 최고속에
  대응시킨 표시용 환산.
- **배경**: 디자인 브랜치의 `bg-{earth,moon,sun,galaxy}.webp` + `satellite.png`로 교체.
  은하 타일은 최원경(패럴랙스 0.1) 수평 반복, 지구는 화면의 절반을 덮는 대형(0.35),
  태양 인접 시 앰버 틴트 ≤8%.

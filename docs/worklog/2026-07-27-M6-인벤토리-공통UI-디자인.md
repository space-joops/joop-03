3. **시안 3프레임** — [mockups/inventory-common-ui.html](../design/mockups/inventory-common-ui.html): ① 인벤토리(탭바 첫 등장) ② 합성(Forge 슬롯+레시피) ③ **공통 UI 갤러리**(토스트·다이얼로그·탭바·버튼 상태).

## 결정한 것들 (문제 → 선택지 → 이유)

### 1. 아이템 아이콘은 고유색, 탭 아이콘은 currentColor
- UI 아이콘(내비게이션)은 상태에 따라 색이 바뀌므로 currentColor가 맞고, **아이템은 색이 곧 정체성**(자석=빨강, 배터리=그린…)이라 고유색 SVG가 맞다. 인벤토리 규칙의 "색은 가능하면 currentColor"를 이 기준으로 해석해 명문화했다.

### 2. 수거물 아이콘 = 쓰레기 스프라이트 재사용
- 인벤토리의 수거물 그리드는 debris-sheet 지오메트리를 아이콘으로 그대로 사용 — "게임에서 주운 것 = 인벤토리에서 보는 것"의 1:1 시각 일치. 별도 아이콘을 만들면 두 표현이 어긋나기 시작한다.

### 3. 다이얼로그는 되돌릴 수 없는 액션 전용
- 합성·수거처럼 **얻는** 행동은 토스트(3초 자동 소멸)로, 아이템 사용·청약 변경처럼 **잃는** 행동만 확인 다이얼로그로. 확인 피로를 줄이면서 실수 비용이 큰 곳에만 마찰을 둔다. 다이얼로그의 코너 나사 도트는 보급 카트리지(M2)와 같은 카세트퓨처리즘 시그니처.

### 4. 탭바 노출 규칙
- 지도·인벤토리·랭킹·설정에서만 상시 노출, 게임 장면(미니게임·아케이드·발사 시퀀스)과 온보딩·첫 화면에서는 숨김. 몰입 화면과 관리 화면을 내비게이션 유무로 구분 — 로그인 후에는 지도가 홈이 된다.

## 검증

- 시안 3프레임 스크린샷 검수(아이템 셀 0개 상태, 레시피 재료 부족 상태, 토스트 2종, 다이얼로그, 탭 활성 글로우 포함).
- 신규 SVG 8종 총 ~6KB, 스크린샷 ~180KB.

## 디자인 발주 전체 회고 (M1~M6)

- 6개 PR(#9 → #10 → #14 → #17 → #18 → 이번)로 **브리프 1·2순위 전체**를 납품: 토큰 v1.0 → 브랜드/PWA → 온보딩+캐릭터 → 미니게임/청약+쓰레기·조이스틱 → 발사/지도+로켓 → 아케이드+천체·위성 → 인벤토리+공통 UI.
- 일관 원칙: ① 정적인 것은 에셋, **동적인 것은 수치 명세**(조이스틱·화염·파티클) ② 시안은 그림이 아니라 **동작하는 레퍼런스**(Canvas 구현·인터랙션·실에셋 로드) ③ 사진 대신 절차 생성(라이선스·용량·일관성) ④ display 폰트는 숫자·라틴 전용.
- 남은 것(디자인 범위 밖 또는 요구 미확정): 관리자 콘솔(M8, 운영 UI), 프렌드십 확장(FR-9.3, 요구 확정 후), 한국어 픽셀 폰트 도입 검토(서브셋).

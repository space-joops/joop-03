# 인앱 스플래시 화면 (매 방문 · 최소 노출 · 스킵)

## 문제 상황

PR #38에서 iOS 네이티브 스플래시(`appleWebApp.startupImage`)를 연결했지만, 이것은
**설치형(standalone) + 해상도가 정확히 일치하는 iOS 기기**에서만 뜬다. 브라우저
접속(개발 확인 포함)에서는 아무것도 보이지 않아 "스플래시가 안 뜬다"는 피드백이
나왔다. 또 네이티브 스플래시는 로드가 빠르면 순식간에 지나가 브랜드 노출이 안 된다.

## 결정

**앱 레벨 스플래시**(`components/splash-screen.tsx`)를 게임 루트 레이아웃에 추가:

- **매 방문 표시**: 초기 상태가 "표시"라 SSR 첫 페인트부터 보인다(앱 화면이 먼저
  번쩍이지 않음). 전체 로드마다 다시 뜨고, SPA 내비게이션에는 뜨지 않는다(레이아웃
  유지) — "새로고침/재진입 기준 매번"으로 해석.
- **최소 노출 2.8초** 후 300ms 페이드아웃. 노출 시간 동안 앰버 부팅 진행 바가
  채워져 "너무 빨리 지나가는" 느낌을 없앤다.
- **스킵 버튼**(하단, i18n `common.skip`) — 누르면 즉시 페이드아웃.
- reduced-motion: 진행 바 정지(가득 참) + 페이드 제거, 자동 종료는 동일.
- z-70 (스캔라인 40 · VersionBadge/PWA 배너 50 위). admin 트리 미적용.

영속 숨김(localStorage "오늘 하루 보지 않기" 등)은 넣지 않았다 — 요구가 "매번"이고,
2.8초 + 스킵이면 부담이 낮다. 필요해지면 후속.

## 검증

- `tsc` / `lint` / `build` 통과
- Playwright: 진입 직후 표시 → 2.1초 시점 유지 → 3.9초 시점 사라짐, 리로드 시
  재표시, 스킵 즉시 닫힘, reduced-motion 정지 바 + 자동 종료 (스크린샷 확인)

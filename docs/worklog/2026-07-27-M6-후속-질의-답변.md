# 2026-07-27 · M6 후속 — 개발팀 적용 질의 4건 답변

## 무엇을 했나

개발팀이 공통 UI 가이드를 main에 적용(PR #22)하면서 PR #19에 남긴 질의 4건에 답했다. 스펙 공백이 확인된 1건(미출시 탭)은 [핸드오프 M6 §4-3](../design/handoff-m6.md)에 정식 스펙으로 보강해 같은 브랜치에 커밋했고, 나머지 3건은 정본 확정·설명으로 종결했다.

## 결정한 것들 (문제 → 선택지 → 이유)

### 1. 미출시 탭 스펙 — 인터림(muted + op 40% + 무반응)을 그대로 추인하지 않고 두 가지를 고쳤다

- **문제**: 지도(M4)·인벤토리(M6) 화면이 없어 개발팀이 인벤토리·랭킹 탭을 임의 처리(muted + opacity 40% + 탭 불가 + `title="준비 중"`)했는데, 가이드에 이 상태 자체가 없었다.
- **선택지**: ① 인터림 그대로 추인 ② opacity·피드백만 보정 ③ "준비 중" 캡션을 라벨에 병기.
- **결정**: ②. 색은 `--color-muted` 유지(추인), **opacity는 40% → 55%**, **무반응 → 정보 토스트 "준비 중이에요"**.
  - opacity 55%: 이 시스템의 "흐림" 문법은 이미 .55(수량 0 아이템 셀)·.6(재료 부족 레시피 행)으로 잡혀 있다. 40%는 muted가 surface 위에서 대비 약 2:1로 떨어져 "지워진" 상태가 된다 — 카세트퓨처리즘의 꺼진 계기는 저휘도로 **존재**해야지, 소거되면 안 된다.
  - 토스트 응답: 무반응 버튼은 "고장"으로 읽힌다. 관제 콘솔은 죽은 버튼에도 응답한다 — §4-1 정보 토스트(3초)로 통일. `aria-disabled` + 포커스 가능은 유지.
  - 캡션 병기(③) 기각: 높이 56에 아이콘 22 + 라벨 11/14 + 캡션 3단은 과밀. 상태 안내는 토스트가 담당.
  - `--color-primary-dim` 기각: "꺼진 세그먼트"용 인광 토큰이라 오히려 "곧 켜질 것 같은 = 탭 가능해 보이는" 뉘앙스를 만든다. 비활성 계열은 muted가 맞다.

### 2. 인터림 내비(M4 이전 홈 = 궤도 대시보드 + 탭바) — 추인·명문화

- 기존 규칙은 "로그인 후 지도 화면이 홈"이었는데 지도가 아직 없다. 로그인 사용자의 홈 = 궤도 대시보드 + 탭바 노출(지도 탭 = 홈, 활성)로 인터림을 추인하고 §4-3에 명문화했다. M4 출시 시 지도 탭의 **목적지만** 바뀌고 탭 4개 구조·순서는 불변 — 개발이 갈아엎을 일이 없도록 경계를 못 박았다.

### 3. 아이템 아이콘 정본 = `public/ui/item-*` 32 그리드 5종

- #16의 `public/game/item-{magnet,health,fuel}.svg`(48 그리드, 구 팔레트)는 워크로그에도 "1차 SVG 시안"으로 명시된 초안이다. #19에서 32 그리드·v1.0 팔레트·5종(`battery` 명명)으로 재설계하며 에셋 인벤토리를 완결했으므로 구 3종은 폐기 대상으로 선언, 삭제는 개발팀 PR에 위임했다.

### 4. 파일 ↔ 시안 인라인 불일치 — 파일이 정본

- 시안 HTML의 인라인 아이콘은 22~30px 축소 렌더 프레임용 간략판(궤도 타원·분사구 삼각형·분사선 등 미세 요소 생략)이다. 시안은 레이아웃·상태 레퍼런스이고 **에셋의 정본은 언제나 `public/` 파일**. 렌치는 레시피 리스트 4행 구성상 시안에 안 등장했을 뿐, 인벤토리 아이템 5종 완결을 위한 정식 납품분이다.

### 5. 로고 v1.0 — 신규 납품 불필요, 이미 스택에 있음

- 요청받은 "v1.0 팔레트 갱신본"은 이미 디자인 스택(#9 이후)의 `public/brand/logo-symbol.svg`에 있다: **64 그리드 currentColor 단색 재설계**(876B). 색을 하드코딩하지 않고 사용처에서 `color`로 주입하므로 팔레트 교체 문제가 원천적으로 사라진다. main 반영은 파일 복사면 충분 — 단 currentColor 특성상 `next/image`가 아닌 **인라인 SVG 또는 CSS mask**로 써야 한다는 점을 코멘트에 명시했다.

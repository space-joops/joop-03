# 2026-07-27 · 첫 화면: 궤도 배속(4단계) + 2D 궤도 추적 모니터

"메인 화면 지구본 위의 줍스들이 궤도 운동을 하게 해달라"는 요청에서 출발해, 배속 컨트롤과 위성 관제 화면풍 2D 추적 뷰를 붙인 기록입니다.

## 줍스는 사실 이미 움직이고 있었다

점검해 보니 첫 화면은 처음부터 "서버 스냅샷 + 클라 rAF 보간" 구조가 완성돼 있었습니다. `orbital-canvas.tsx`는 매 프레임 `positionAt(orbit, Date.now()/1000, 0)`을 다시 계산하고, `/api/orbital`은 좌표가 아니라 **궤도 파라미터를 통째로** 보내며, `lib/orbit.ts`는 서버·클라가 같은 파일을 import 합니다.

그런데 왜 정지로 보였을까요? **각속도가 실제 위성 수준이기 때문입니다.**

- 시드 ω = 0.0008~0.00164 rad/s → **1바퀴 64~131분** (실제 ISS가 92분입니다)
- 화면 스케일로 환산하면 접선 속도 **0.1~0.3 px/초**, 프레임당 1/200 픽셀

즉 "궤도 운동 구현"이 아니라 **"체감 배속"**이 필요한 문제였습니다. 60fps로 열심히 그리는데 아무도 알아볼 수 없었던 거죠.

## 왜 물리값(ω) 대신 표시 배속인가

DB의 ω를 60배로 올리면 간단히 보이게 되지만, `lib/space.ts`가 우주 지도 계기(속도 km/s)를 `ω·r·6371`로 계산하므로 **지표가 초속 400km 같은 비현실 값**이 됩니다. 그래서 물리값은 그대로 두고 렌더링 시각만 가속했습니다. 지표(고도·속도)는 궤도 상수라 배속과 무관하게 실측치를 유지합니다.

## 가상 시계 — 배속을 바꿔도 위치가 튀지 않게

`positionAt(orbit, t × 배속, 0)`처럼 절대 시각에 배속을 곱하면 배속을 바꾸는 순간 위상이 수천 라디안 점프합니다(t가 유닉스 시각이라 값이 큽니다). 대신 `lib/orbit-clock.ts`의 **가상 시계**가 프레임마다 `vt += 실경과 × 배속`으로 전진합니다.

- 배속 변경·뷰 전환에도 위치 연속 (지구본과 추적 뷰가 같은 시계를 공유)
- 초기값 = 현재 실시각 → **1×에서는 서버가 계산하는 실위치와 일치**
- 탭 복귀 시 실경과를 0.5초로 잘라 960×에서 수십 바퀴 점프하는 것 방지

배속은 1× / 60× / 240× / 960× 4단계, 기본 60×(1바퀴 약 1~2분). 사용자 요청대로 **서버와 무관한 클라이언트 값**이라 config 키도 없습니다.

## 2D 궤도 추적 모니터 (`components/orbit-track-map.tsx`)

지구본을 equirectangular로 펼친 위성 관제 화면입니다.

- **배경 세계지도**: `scripts/generate-world-map.mjs`가 Natural Earth 110m(devDeps `world-atlas`)을 144×72 육지 비트 그리드로 래스터화 → `lib/world-map-grid.ts`(3.7KB)로 커밋. 픽셀 블록 미감이 카세트퓨처리즘과 맞아 일부러 셀 사이 틈을 남겼습니다. 프레임마다 3천여 셀을 다시 칠하지 않도록 오프스크린 캔버스에 1회 렌더.
- **지상 궤적**: `lib/orbit.ts`에 추가한 `groundStateAt` — ECI 좌표를 위경도로 바꾸되 **지구 자전(7.29e-5 rad/s)을 배속과 함께** 되돌려, 실제 관제 화면처럼 궤적이 서쪽으로 드리프트하는 사인 곡선이 나옵니다. 관측 대상은 앞뒤 반 주기 궤적 폴리라인 + 조준링 + 십자선으로 강조.
- **관측 대상**: 내 줍스가 궤도에 있으면 내 줍스, 아니면 스냅샷 첫 줍스(첫 화면은 비로그인도 보므로 폴백 필수).
- **음영 반구**: `lib/space.ts`의 규약(태양=+x)을 그대로 지표 경도 밴드로 환산해 밤 지역을 어둡게.
- **지표 패널(DOM)**: 현재 상공(국가/해역 + 좌표) · 고도 · 속도 · 교신/음영. rAF가 아니라 0.5초 틱으로 리렌더.

### "어느 나라 상공인가" — bbox 판정의 한계

정밀 국경 폴리곤(수백 KB)을 랜딩 번들에 싣는 대신, `lib/geo-regions.ts`에 주요 국가 ~49개의 경계 상자 + 해역 폴백을 뒀습니다. 국경 부근·군도에서는 이웃 나라로 표시될 수 있는 **게임 계기판 등급 정밀도**입니다. 참고로 경도는 지구 자전을 보정했습니다 — 우주 지도(`lib/space.ts:84`)는 아직 ECI 경도 그대로라(#36-6) 두 화면의 좌표가 다를 수 있는데, 추적 모니터 쪽이 맞는 값입니다.

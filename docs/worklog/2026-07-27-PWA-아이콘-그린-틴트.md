# PWA 아이콘 배경 그린 틴트 전환 + favicon 파이프라인 편입

## 문제 상황

PR #25(홈 CRT 투톤 리디자인)에서 앱 배경 토큰이 네이비 틴트(#05070f) → 그린 틴트
블랙(#030a05)으로 바뀌었는데, PWA 아이콘 마스터 SVG의 배경 그라디언트와 로봇 헤드
패널 색은 여전히 네이비 계열이었다(당시 worklog에 후속 항목으로 기록). 설치
화면/스플래시에서 `manifest.background_color`와 아이콘 배경 톤이 어긋난다.

부수 문제: `app/favicon.ico`(16/32)는 `gen:icons` 파이프라인 밖의 수동 산출물이라
브랜드 색이 바뀌어도 재생성이 안 됐다.

## 선택지와 결정

### 색 전환 방식

- A. 새 팔레트를 눈대중으로 다시 뽑기
- B. **네이비 hex의 G↔B 채널 스왑** ← 채택

네이비는 B 채널 우세, 그린 틴트는 G 채널 우세라 채널만 바꾸면 명도가 거의 보존되면서
색상(hue)만 phosphor 방향으로 돌아간다. 형광 그린(#35e07a)·앰버(#ffb23e)·그리드
(#1e5a46) 등 토큰과 일치하는 색은 그대로 두고, 네이비 계열 10개만 치환했다:

| 기존 | 변경 | 위치 |
|---|---|---|
| #0c1626 / #070c16 / #04060d | #0c2616 / #07160c / #040d06 | 배경 라디얼 그라디언트 |
| #14212e | #142e21 | 콘솔 베젤 |
| #16202e / #26374a / #33475c | #162e20 / #264a37 / #335c47 | 로봇 헤드 |
| #0e1622 / #2a3646 | #0e2216 / #2a4636 | 마운팅 볼트 |
| #0a1018 | #0a1810 | CRT 글라스·스캔라인 |

대상: `public/design-src/icons/icon-master.svg`, `icon-maskable-master.svg`,
그리고 마스터의 복사본인 `public/icon.svg`.

### favicon 처리

- A. 이번에도 수동으로 두기
- B. **`scripts/generate-icons.mjs`에 편입** ← 채택

sharp는 ICO를 직접 못 쓰지만, ICO 포맷은 PNG 임베드를 허용한다(모던 브라우저 전부
지원). 16/32 PNG를 sharp로 래스터한 뒤 ICONDIR(6B) + ICONDIRENTRY(16B×n) + PNG
블롭을 이어 붙이는 소형 패커(`packIco`)를 스크립트에 넣었다 — 신규 의존성 없음.
이제 `npm run gen:icons` 한 번으로 PNG 4종 + favicon.ico가 전부 마스터에서 파생된다.

## 검증

- `npm run gen:icons` 재생성 → icon-512/maskable-512 육안 확인 (배경 그린 틴트, 마크
  손상 없음), 전 파일 200KB 이하 (최대 23KB)
- `file app/favicon.ico` → 16/32 PNG 2장 포함 유효 ICO
- `npm run build` 통과

## 남은 것

- 나머지 게임 화면(온보딩/내 줍스/훈련/발사/지도/청약)과 관리자 콘솔 투톤 적용은
  여전히 후속 후보 (화면별 현황 조사 완료 상태).

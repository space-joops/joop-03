  - **관성·마찰 0**(FR-7.5): `lib/arcade.ts` 순수 물리. 분사를 멈춰도 속도가 유지된다.

## 핵심 결정과 이유

### 보상은 XP가 아니라 수거량

지상 훈련(M3)의 보상은 XP(발사 자격)였지만, 궤도에 오른 줍스에게 레벨은 이미 큰 의미가 없습니다. 아케이드의 수거는 게임의 최종 지표인 **전체 청소량과 랭킹**으로 직결시켰습니다 — `settleIdleCollection`과 같은 테이블 규약(`debris_events` + `total_collected`)이라 별도 집계가 필요 없습니다. 쓰레기 종류별 가치(캔 3·패널 5·볼트 1…)는 debris-sheet 메타의 `value`를 그대로 씁니다.

### 상한은 거부가 아니라 클램핑

지상 훈련은 치팅 상한 초과를 통째로 거부해서, 관리자가 판을 길게 만들면 정상 플레이어가 몰수당할 수 있었습니다(이슈 #36-1). 아케이드 액션(`submitArcadeResult`)은 상한으로 잘라서 반영합니다. `total_collected` 갱신은 낙관적 가드(`.eq` + `.select()` 확인 + 재시도)로 자동 수거 정산과의 경쟁을 견딥니다 — PostgREST에서 조건 불일치는 오류가 아니라 0행이므로 **갱신 행 수를 확인해야** 합니다(이슈 #31에서 배운 것).

### 옛 물리의 회수 — 프레임 기반 → 시간 기반

M3 초기의 분사 물리(`applyThrust`)를 git 이력에서 되살리되, 프레임 기반(px/frame)이라 주사율에 따라 체감이 달라지던 것을 **초 단위 시간 기반**(units/s², dt 곱)으로 재정비했습니다. 월드 단위 1.0 = 화면 최소변이라 기기 크기와 무관하게 같은 감각입니다.

### 수신 게이트는 관리자 토글

FR-6.6대로 기본은 음영에서 진입 불가(`arcade_require_link=1`)지만, 실제 음영 주기는 실시간 30~65분이라 테스트가 답답할 수 있습니다. 관리자 콘솔에서 0으로 끄면 항상 진입됩니다. 물리·생성·연료 등 8개 파라미터 모두 `arcade_*` config로 콘솔에서 조정 가능(EPIC 10).

### FR-7.1("지상과 동일 조작")의 재정의

지상 훈련이 좌우 식별 게임으로 바뀌면서 "동일 조작"은 성립하지 않게 됐습니다(requirements.md FR-7.1 경고 참조). 지상 = 식별 훈련, 아케이드 = 5원 조이스틱 + 관성 — 요구사항의 원문 조작 스펙(FR-7.4/7.5)은 아케이드 쪽이 온전히 구현합니다.

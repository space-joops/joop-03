# 2026-07-28 — 아케이드 우주 배경 실사화 + gen:game 파이프라인 (v0.12.0)

## 배경

사용자가 아케이드의 지구·태양·달·은하수와 우주 배경 전반이 마음에 들지 않는다며,
ISS 선외활동 실사 사진(구름 낀 파란 지구, 얇은 청색 대기 림, 칠흑 우주)을 레퍼런스로
"실제 우주 유영을 하는 느낌"을 요청했다. 디자인 파일(마스터)도 함께 만들 것.

문제를 뜯어보니 세 가지가 겹쳐 있었다:

1. **지구에 대륙이 없었다.** 기존 마스터는 그라데이션 + 흰 타원 176개(구름)로만 이루어진
   "구름 낀 바다 행성"이라, 지구처럼 보이지 않았다.
2. **해상도 부족.** 1024² 소스가 실기기(DPR 2~3)에서 최대 2.8배로 확대되어 뭉개졌다.
3. **재생성 불가.** webp가 디자인 브랜치에서 반입된 수동 산출물이라, 마스터를 고쳐도
   다시 뽑을 스크립트가 없었다 — `gen:icons`가 보장하는 마스터→파생 규칙의 유일한 구멍.

참고: "잘 보면 보이는 가로줄"은 배경이 아니라 전역 CRT 스캔라인 오버레이
(`globals.css` `.crt-scanlines::after`)였다. 레트로 터미널 컨셉의 일부라 사용자 확인을
받았고 **일단 유지**하기로 했다.

## 제약과 선택

- **NASA 실사진은 못 쓴다.** 이 개발 환경의 네트워크 정책이 nasa.gov 계열을 차단한다
  (프록시 403). 사용자 승인 하에 **전부 로컬 프로시저럴 생성**으로 방향을 잡았다.
- **래스터는 librsvg(sharp)가 아니라 Chromium.** 이번 마스터의 핵심이 feTurbulence /
  feDisplacementMap 필터(구름·레골리스·은하 밴드)인데 librsvg는 이 필터 구현이
  불완전하다. Playwright로 Chromium을 띄워 스크린샷으로 래스터하면 디자이너가
  브라우저에서 여는 프리뷰와 산출물이 픽셀 일치한다.
- **대륙은 SVG 필터로 못 만든다.** 구면 투영이 필요해서다. 이미 devDependency로 있던
  `world-atlas`(Natural Earth 50m)를 등장방형 마스크로 굽고, **역직교투영**(픽셀→위경도)
  per-pixel 렌더로 `bg-earth-land.png`(1660²)를 생성해 지구 마스터가 `<image>`로 참조한다.
  역투영이라 지평선 폴리곤 클리핑이 필요 없고, 마스터는 단독으로 브라우저에서 열린다.

## 무엇을 만들었나

`npm run gen:game` (`scripts/generate-game-bg.mjs`) — 실행 순서:
별밭 주입(은하 마스터의 `@stars` 마커 구간, 시드 PRNG라 결정적·멱등) → 대륙층 PNG →
마스터 4종 Chromium 렌더 → sharp webp 인코드 → 크기 게이트(초과 시 품질 −8 재시도).

| 에셋 | 해상도 | 결과 | 비고 |
|---|---|---|---|
| bg-earth.webp | 2048² | ~148KB | 실지형 대륙 + feTurbulence 소용돌이 구름 + 대기 림 + 터미네이터 |
| bg-moon.webp | 1536² | ~27KB | 레골리스 노이즈 + 마리아 + 저대비 크레이터 |
| bg-sun.webp | 1792² | ~247KB | 순백 코어 + 과다노출 글로우(만화 광선 제거) |
| bg-galaxy.webp | 3072×1536 | ~28KB | 밴드+더스트 레인+별밭 1,200개, 수평 심리스 |

합계 ~450KB(기존 ~190KB) — 아케이드 진입 시에만 로드되므로 수용.

인게임 보정(`arcade-game.tsx` drawBackground, 최소):
- 딥스페이스 클리어색 `#03060d` → `#010208`(칠흑 — 색감은 은하 타일이 담당).
- 프로시저럴 별을 정사각 `fillRect` → **원 + 색온도 4종 팔레트**(웜화이트/백/청/주황,
  은하 마스터 별밭과 같은 분포) + 반경 ±30% 변주.
- 은하 타일 알파 0.9 → 0.95.

## 배운 것 / 함정

- **은하 타일의 수평 심리스**는 세 가지 규칙의 합이다: ① 모든 feTurbulence 에
  `stitchTiles="stitch"` + 필터 영역을 타일 크기에 정확히 일치(userSpaceOnUse), ② 밴드
  사각형을 타일 밖까지 연장(x방향 균일이라 왜곡 후에도 연속), ③ 별밭은 가장자리 24px
  별을 반대편에 복제. 하나라도 빠지면 반복 경계에 줄이 생긴다.
- **feComposite operator="in"의 알파 곱 함정**: 노이즈를 밴드 모양으로 클립하면 결과
  알파가 `노이즈 α × 밴드 α`라, 밴드(최대 0.27)를 마스크로 쓰면 거의 안 보인다.
  더스트 레인은 알파 0.9짜리 전용 마스크 그라데이션을 따로 뒀다.
- **달은 블러를 아끼는 게 사실감**이다. 첫 판은 blur 4 크레이터 + 저주파 노이즈로
  "안개 낀 공"이 됐다. blur 2 + 노이즈 주파수 2배 + 마리아 진하게로 잡았다.
- Chromium 버전이 바뀌면 feTurbulence 결과가 미세하게 달라질 수 있다 — 산출물 webp를
  커밋하므로 실서비스 영향은 없고, 재생성 시에만 diff가 날 수 있다.

## 후속 튠 (v0.13.0, 같은 날)

병합 후 사용자가 스타일 레퍼런스(밝은 하늘색 행성 + 백색 발광 림 + 지평선 위 달)를
추가로 주며 "실제에 가까운 크기 비율"과 "이런 지구 느낌"을 요청했다.

- **크기 비율(lib/arcade.ts)**: 지구 2.6→3.2u·y 2.0(지평선처럼 하단을 가득),
  달 1.0→0.55u(지구 대비 확연히 작게), 태양 1.8→1.1u(원반은 작고 글로우는 넓게).
- **지구 톤(bg-earth-master + 대륙 팔레트)**: 해양을 밝은 하늘색 계열로, 대기 림을
  두껍고 하얗게(86→100% 대역) + 림 안쪽 백색 헤이즈 추가, 터미네이터 얕게,
  구름 커버리지 소폭 증가. 대륙 팔레트는 파스텔 + 전면 22% 바다색 혼합으로
  "빛나는 행성" 톤에 스며들게.
- **달**: 회색 → 살짝 웜톤(레퍼런스의 황갈색 달).

전부 마스터·스크립트 수정 → `gen:game` 재생성. 코드 변경은 CELESTIALS 수치뿐.

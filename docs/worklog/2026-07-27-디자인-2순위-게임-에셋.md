# 2026-07-27 · 디자인 2순위 — 게임 에셋(캐릭터·쓰레기·천체·조이스틱·위성) SVG 시안

에셋 인벤토리 "C. 게임 에셋(후속)"을 **1차 SVG 벡터 시안**으로 제작한 기록입니다. 아케이드 화면(M5)은 아직 착수 전이라, 지금은 앱 코드에 붙이지 않고 **정적 파일 + 문서**만 남깁니다.

## 왜 SVG 시안으로 먼저 갔나

인벤토리 원안은 게임 스프라이트를 PNG/WebP(+시트)로 예정했지만, 아케이드 렌더가 아직 없어 최종 프레임 규격(앵커·시트 좌표)이 확정되지 않았습니다. 그래서:

- **벡터 SVG로 먼저** 컨셉·비율·팔레트를 확정하면, 이후 Canvas 렌더 단계에서 필요한 크기로 PNG/WebP + 좌표 JSON을 손실 없이 재출력할 수 있습니다.
- 파일이 가볍고(전부 합쳐 ~43KB) diff·리뷰가 쉬우며, 색 변형을 `currentColor` 로 처리해 변형 관리가 단순합니다.
- 규칙(`docs/design/README.md`)대로 원본은 `public/design-src/game/`, 산출물은 `public/game/` 에 동일 SVG로 배치했습니다(브랜드 에셋과 같은 미러 방식).

## 무엇이 나왔나 (`public/game/`, 총 19개 SVG)

- **줍스 캐릭터** — `joop-{green,amber,cyan}.svg`. 정면/대기 포즈 1종. 브랜드 심볼(CRT 얼굴·안테나 앰버 비컨·형광 눈)과 일관되게 전신화: 집게 팔(수거)·가슴 계기판·하부 스러스터. **몸통 주요 색은 root `color` → `currentColor`** 로 두어 색 변형은 루트 속성 하나만 바꿈. 앰버 비컨은 브랜드 고정색.
- **우주 쓰레기 6종** — `debris-{satellite-fragment,bolt,can,circuit,panel,antenna}.svg`. 살짝 회전시켜 "표류하는 파편" 느낌. 다크 금속 + 그리드 그린 + 앰버 경고 포인트.
- **배경 천체** — `celestial-earth.svg`(경위도 그리드 + 형광 대륙 + 대기 림 + 터미네이터), `celestial-moon.svg`(크레이터/마리아), `celestial-sun.svg`(앰버 광구 + 형광 코로나 발광, radial gradient), `celestial-milkyway.svg`(512×200, **가로 심리스 타일**: 성운 그라디언트를 x축 균일하게 두고 별을 가장자리 16px 안쪽에만 배치해 이음매 없음).
- **5원 반투명 조이스틱** — `joystick.svg`. 구성 원 5개(베이스·가이드 링·데드존·노브 외곽·노브 코어) + **분사량 라디얼 게이지**(12틱 중 상단 편향 ~60% 점등, 노브를 위로 밀어 추력 벡터 표현). 반투명 HUD.
- **위성 2종** — `satellite-comm.svg`(근경/대형: 태양전지 양날개·고이득 접시·MLI 포일·스러스터), `satellite-probe.svg`(원경/소형: 큐브 버스). 원근 스케일 변형용.
- **아이템 아이콘 3종** — `item-{magnet,health,fuel}.svg`. 자석(자기장선 + 시안/앰버 극)·체력(형광 크로스 배지)·연료(앰버 게이지 캐니스터).

모두 `viewBox` 명시, 투명 배경, 다크 표면 위 사용 전제. 색은 확정 토큰(bg `#05070f`·surface `#0f1826`·primary `#35e07a`·secondary `#ffb23e`·accent `#38e0f0`·grid `#1e5a46`)만 사용.

## 검증

- 19개 SVG 전부 XML well-formed 확인(`xml.dom.minidom` 파싱 통과).
- 앱 코드·빌드 설정은 손대지 않음(아케이드 M5 전이므로 정적 파일 + 인벤토리/워크로그 문서만).
- 로컬에 SVG 래스터라이저가 없어 PNG 프리뷰는 생략, 대신 좌표 기하 수기 검수(집게 팔·터미네이터 방향·조이스틱 노브 오프셋·은하수 타일 마진).

## 남은 것 / 다음

- **분사가스/이펙트 파티클 시트**는 미제작(정지 표현은 캐릭터·조이스틱에 포함). Canvas 렌더 규격 확정 후 프레임 시트로.
- 줍스 캐릭터 **이동·수거 프레임**(현재 대기 1종만).
- M5 아케이드 착수 시 SVG → PNG/WebP + 좌표 JSON 재출력, 앵커·여백 규칙 확정.
- 실제 렌더 환경에서 시각 QA(형광색 위 대비, 축소 시 디테일 뭉개짐).

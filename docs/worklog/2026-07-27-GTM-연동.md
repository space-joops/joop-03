# 2026-07-27 · Google Tag Manager 연동

사이트 방문·행동 데이터를 보고 싶다는 요청으로 Google Tag Manager(GTM)를 붙였습니다.

## 문제 상황

이 프로젝트엔 방문자 추적 수단이 전혀 없었습니다. 트래킹을 붙이려면 Next.js 쪽에서 서드파티 스크립트를 어떻게 안전하게 로드할지, 그리고 이 앱의 두 개 독립 루트 레이아웃(게임 트리 `app/[lang]/layout.tsx` / 관리자 콘솔 `app/admin/layout.tsx`) 중 어디에 넣을지 결정이 필요했습니다.

## 결정

- **관리자 콘솔은 제외, 게임 트리에만 적용.** `app/admin/layout.tsx`는 이미 `robots: {index:false, follow:false}`로 검색·추적 관심사에서 의도적으로 빠져 있어(PWA 프롬프트·스플래시·CRT 오버레이도 전부 admin 미적용), 같은 원칙을 따랐습니다.
- **`@next/third-parties`의 `GoogleTagManager` 컴포넌트 사용.** Next.js 공식 서드파티 통합 패키지로, 이 저장소의 `next` 버전(16.2.12)과 동일 버전으로 설치했습니다. 이전에는 `next/script`나 다른 서드파티 스크립트 로딩 사례가 전혀 없었어서 새로 도입.
- **동의(consent) 배너는 이번엔 생략.** 이 프로젝트엔 쿠키/추적 동의 메커니즘이 전혀 없고, 10개국어 대상 글로벌 서비스라 EU 등 지역의 동의 규제가 걸릴 수 있다는 점을 알렸으나, 사용자가 지금은 배너 없이 바로 적용하기로 결정했습니다. 나중에 지역 규제 대응이 필요해지면 별도 작업으로 배너를 추가할 것.
- **컨테이너 ID는 환경변수가 아니라 코드에 하드코딩.** GTM 컨테이너 ID는 페이지 소스에 그대로 노출되는 값이라 비밀값이 아니고, 사용자가 명시적으로 하드코딩을 요청했습니다(`app/[lang]/layout.tsx`의 `GTM_ID` 상수). 이 저장소의 다른 외부 서비스 값(Supabase URL 등)은 환경변수 컨벤션을 쓰지만, 이번엔 요청대로 예외로 두었습니다.

## 구현

- `package.json` — `@next/third-parties` 의존성 추가.
- `app/[lang]/layout.tsx` — `<html>` 바로 아래(공식 문서 예제와 동일한 위치 — `<body>` *안*이 아니라 `<html>`의 직계 자식)에 `<GoogleTagManager gtmId={GTM_ID} />` 배치. `GTM_ID = "GTM-NV8BSHG2"`.

## 검증

- `npm run build` 통과.
- `.next` 캐시를 지운 클린 빌드 + `npm run start`로 확인:
  - `/en` 응답의 RSC 페이로드에 `{"gtmId":"GTM-NV8BSHG2"}`가 실려 있는 것을 확인 — 컴포넌트가 올바른 ID로 게임 트리 전 페이지에 배선됨.
  - `/admin` 응답에는 GTM 관련 문자열이 전혀 없는 것을 확인 — 의도대로 관리자 콘솔 제외.
  - `curl`로 받은 정적 HTML에는 `googletagmanager.com` `<script src>` 태그가 직접 보이지 않는데, 이는 버그가 아니라 `GoogleTagManager` 컴포넌트가 `next/script`의 `afterInteractive` 전략을 쓰기 때문입니다("하이드레이션 이후에 원본 인라인 스크립트를 가져온다" — 공식 문서 문구). 실제 브라우저에서 하이드레이션이 끝난 뒤 `gtm.js`가 클라이언트에서 동적으로 삽입되므로, 정적 HTML만 보는 curl 검증으로는 이 단계까지 확인할 수 없는 게 정상입니다.
- 실제 GTM/GA 대시보드에서 이벤트 수신 확인은 배포 후 사용자가 직접 확인해야 합니다(이 세션 네트워크 정책이 `*.vercel.app`을 막고 있어 실배포 검증 불가 — 기존에도 반복된 제약).

## 범위 밖

- 쿠키/추적 동의 배너 (이번엔 생략하기로 결정).
- GTM 컨테이너 안의 실제 태그(GA4 연결, 이벤트 정의 등) 설정은 GTM 콘솔에서 사용자가 직접 구성해야 합니다 — 이 작업은 컨테이너를 사이트에 "연결"하는 것까지입니다.

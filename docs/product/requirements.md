# 줍스 — 요구사항 명세

> 출처: GitHub 이슈 [#2 "요구사항-1"](https://github.com/space-joops/joop-03/issues/2).
> 이 문서는 이슈의 산문을 **에픽(EPIC)** 과 **기능 요구사항(FR)** 으로 구조화한 것입니다. 각 FR에는 이슈의 어느 화면에서 나온 것인지(화면 태그)와 우선순위를 표기합니다.

## 표기 규칙

- **우선순위**: `MVP`(M1 첫 화면) / `핵심`(초기 필수) / `후속`(확장)
- **화면**: 이슈의 첫/둘/셋/넷째 화면 구분
- FR 번호는 안정적으로 유지합니다(문서/PR/커밋에서 `FR-1.3`처럼 참조).

---

## EPIC 0 · 기반 (Foundation)

모든 화면의 토대. 개별 기능이라기보다 횡단 관심사.

- **FR-0.1** 〔핵심〕 **i18n**: 10개 주요 언어 지원, 설정에서 변경, 폴백 영어. → [ADR-0001](../architecture/adr/0001-i18n.md)
- **FR-0.2** 〔핵심〕 **PWA**: 홈 화면 설치, **세로 화면 고정**, 버전업 대응. → [ADR-0002](../architecture/adr/0002-pwa-portrait.md)
- **FR-0.3** 〔핵심〕 **디자인 시스템**: 카세트퓨처리즘 UI 토큰/컴포넌트.
- **FR-0.4** 〔핵심〕 **데이터 계층**: Supabase(공유 jd-04, `joop_03_` 접두사) 클라이언트·스키마·RLS. → [data-model](../architecture/data-model.md)
- **FR-0.5** 〔핵심〕 **인증 뼈대**: Supabase Auth 세션, 서버/클라 클라이언트. → [ADR-0004](../architecture/adr/0004-auth-invite.md)

## EPIC 1 · 첫 화면 — 궤도 대시보드  ⭐MVP  〔첫째 화면〕

- **FR-1.1** 〔MVP〕 로그인하지 않아도 접근 가능한 공개 화면.
- **FR-1.2** 〔MVP〕 지구 궤도를 도는 **줍스 100개**를 지구본 + 궤도 위에 현재 좌표로 표시.
- **FR-1.3** 〔MVP〕 좌표는 **서버에서 10초(설정 가능)마다 계산**되어 API로 제공. → [ADR-0005](../architecture/adr/0005-ssr-orbital-api.md)
- **FR-1.4** 〔MVP〕 클라이언트는 **같은 계산 로직**으로 좌표를 보간(공식은 실제 물리 기반이나 게임용 단순화). → [orbit-model](../architecture/orbit-model.md)
- **FR-1.5** 〔MVP〕 이들이 치운 **우주 쓰레기 총량과 % 비율** 표시.
- **FR-1.6** 〔MVP〕 청소 **랭킹** 표시.
- **FR-1.7** 〔MVP〕 랭킹의 **주간 등락을 차트**로 제공.
- **FR-1.8** 〔핵심〕 로그인 이후에는 **본인의 랭킹**도 표시.

## EPIC 2 · 온보딩 (분양)  〔둘째 화면〕

- **FR-2.1** 〔핵심〕 미로그인 사용자는 아직 줍스를 분양받지 못함 — **초대 코드**가 필요.
- **FR-2.2** 〔핵심〕 이메일을 입력하고 초대 코드를 기다리거나, 친구의 초대 코드를 입력하면 줍스를 분양받아 게임 시작.
- **FR-2.3** 〔핵심〕 분양 후 **이름(유니크)·색깔 등 간단한 설정**.

## EPIC 3 · 지상 미니게임  〔둘째 화면〕

- **FR-3.1** 〔핵심〕 지상에서 우주 쓰레기를 먹는 **미니게임**으로 조작 학습.
  - **FR-3.1a** 〔핵심〕 줍스는 **땅에 서서 좌우로만** 움직인다(공중 부양 금지 — 지상이라는 장면과 맞춘다).
  - **FR-3.1b** 〔핵심〕 위에서 물체가 떨어지고, **먹어도 되는 우주 쓰레기는 받아내고 충돌하면 안 되는 작동 중 위성은 피한다**. 즉 지상 훈련의 핵심은 **식별**이다.
  - **FR-3.1c** 〔핵심〕 캐릭터(줍스)가 화면에 등장해 반응하고, 잘 받아낼수록 **유대**가 쌓인다(현재는 결과 화면 연출, 영속화는 EPIC 8과 함께).
- **FR-3.2** 〔핵심〕 특정 **레벨**이 되면 우주로 발사 가능(발사 자격).

## EPIC 4 · 발사체 청약  〔둘째 화면〕

- **FR-4.1** 〔핵심〕 **실 우주 발사체 리스트**에서 발사 장소·발사체를 선택해 **청약**.
- **FR-4.2** 〔핵심〕 **관리자**가 발사체 일정을 정하고 **탑승 대상을 선별**.
- **FR-4.3** 〔핵심〕 선별 결과를 게임 화면에서 확인.

## EPIC 5 · 발사 시퀀스  〔셋째 화면〕

- **FR-5.1** 〔핵심〕 탑승 확정 시 **카운트다운** 화면.
- **FR-5.2** 〔핵심〕 발사되면 스페이스X 중계 같은 **발사 중계** 화면.
- **FR-5.3** 〔후속〕 우주 도달 후 발사 장면 **리플레이 및 공유·자랑**.

## EPIC 6 · 우주 지도 / 궤도 상태  〔넷째 화면〕

- **FR-6.1** 〔핵심〕 우주의 줍스 플레이어 위치가 **기지국**이 되며, **음영 지역에서는 자동 모드**로 쓰레기 수거.
- **FR-6.2** 〔핵심〕 실제 위성처럼 음영·송신 주기를 두되, **게임 재미가 떨어지지 않도록 물리계를 조정**(주요 지표는 환경 변수/관리자에서 변경 가능 → EPIC 10).
- **FR-6.3** 〔핵심〕 내 줍스 중심으로 **2차원 지구본 지도**에 궤도 표기, 현재 **어느 나라 상공·속도·고도·상태**를 확인.
- **FR-6.4** 〔핵심〕 주요 지표는 **기본 화면**에도 반영.
- **FR-6.5** 〔핵심〕 내가 발급 가능한 **초대 코드 공유**, 피초대자가 어느 단계에서 어떤 활동을 하는지 확인(→ EPIC 9 보상·프렌드십 연결).
- **FR-6.6** 〔핵심〕 음영 지역이 아닐 때 **사용자에게 알람**을 발송하고, 함께 수거하는 **아케이드 모드 진입** 가능(→ EPIC 7).

## EPIC 7 · 아케이드 모드  〔넷째 화면〕

- **FR-7.1** 〔핵심〕 지상에서 훈련한 것과 **동일한 조작 방식**. 실제 우주 쓰레기와 위성이 지나다니고, 멀리 태양·달·지구·은하수/은하가 보이는 **최대한 우주에 있는 느낌**(NASA 우주 이미지 참고).
  - ⚠️ **조작이 갈라졌다**(2026-07-27): 지상 훈련이 FR-3.1a 대로 "땅에서 좌우 이동"으로 바뀌어, 아케이드의 자유 이동(FR-7.2)·5원 조이스틱(FR-7.4)·관성(FR-7.5)과 더 이상 같지 않다. 지상에서 배우는 것은 **조작**이 아니라 **식별**(무엇을 먹어도 되는지)이라고 보고 이 갈라짐을 받아들였다. M5 착수 시 "동일 조작"의 의미를 다시 정의할 것.
- **FR-7.2** 〔핵심〕 상하좌우 이동 가능, 화면 경계를 넘으면 **배경이 움직여** 지구→달→태양 등이 전환.
- **FR-7.3** 〔핵심〕 다양한 우주 쓰레기가 상하좌우에서 등장, **먹으면 청소**됨.
- **FR-7.4** 〔핵심〕 조이스틱: 화면 아무 곳이나 누르면 **원 5개로 이루어진 반투명 조이스틱**이 나오고 **분사량을 미세 조정**해서 플레이.
- **FR-7.5** 〔핵심〕 **관성 있음, 마찰 0** (관리자에서 설정 가능하면 좋음, 설정값은 게임 재시작 시 반영). → EPIC 10. 서버사이드 렌더링 적극 활용해 부하 최소화.
- **FR-7.6** 〔핵심〕 **분사가스가 떨어지면 게임 종료**, 수집한 쓰레기를 인벤토리에 모음(→ EPIC 8).
- **FR-7.7** 〔후속〕 **사실적인 위성**이 궤도를 따라 점점 다가오거나 멀어지는 효과를 **웅장하고 경이롭게** 표현. (쓰레기는 2D, 위성은 원근 효과.)

## EPIC 8 · 인벤토리 / 합성 / 업그레이드  〔넷째 화면〕

- **FR-8.1** 〔핵심〕 수집한 쓰레기를 **인벤토리**에 모음.
- **FR-8.2** 〔후속〕 아이템을 **합성**해 분사가스·체력·업그레이드(자석·체력·아이템 꾸미기) 제작.

## EPIC 9 · 초대 / 프렌드십 / 보상

- **FR-9.1** 〔핵심〕 초대 코드 발급·공유.
- **FR-9.2** 〔후속〕 피초대자의 단계·활동 추적, **보상**으로 연결될 여지.
- **FR-9.3** 〔후속〕 **프렌드십(friend-ship)** 으로 연결.

## EPIC 10 · 관리자 콘솔

- **FR-10.1** 〔핵심〕 **좌표 계산 주기**(기본 10초) 등 운영 파라미터 설정.
- **FR-10.2** 〔핵심〕 물리계 파라미터(음영·송신 주기, 관성/마찰 등)를 **환경 변수/관리자 화면에서 변경**, 게임 재시작 시 반영.
- **FR-10.3** 〔핵심〕 **발사체 일정** 관리, **탑승 대상 선별**(EPIC 4와 연결).

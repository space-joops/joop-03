# 줍스(Joops) — 제품 개요

> 이 문서는 GitHub 이슈 [#2 "요구사항-1"](https://github.com/space-joops/joop-03/issues/2)의 비전을 요약한 것입니다. 세부 기능은 [requirements.md](./requirements.md), 일정은 [roadmap.md](./roadmap.md)를 참고하세요.

## 한 줄 소개

**줍스**는 지구 궤도에 흩어진 우주 쓰레기를 청소하는 **반려형 우주 로봇**을 시민 각자가 분양받아 키우고 발사해, 다 함께 우주를 청소하는 **모바일 세로 화면 전용 웹 게임(PWA)** 입니다.

## 세계관 / 배경

- 가까운 미래, 인류는 화성 개발에 성공하고 우주여행이 일상이 되었다.
- 동시에 우주 쓰레기 문제가 가속되어, 우려하던 **케슬러 신드롬(Kessler Syndrome)** 이 현실화된다. 파편이 파편을 낳는 연쇄 충돌로 지구 저궤도가 위험해지고, 우주여행의 심각한 장애가 된다.
- 광활한 궤도에 퍼진 미세한 우주 쓰레기를 청소하는 난제를 풀기 위해, 지구 시민 모두가 **줍스**라는 반려형 청소 로봇을 궤도로 발사한다.
- 개인은 모바일 환경에서 자신의 줍스를 관리하며, 전 지구적 협력으로 우주를 청소한다.

## 핵심 게임 루프

```
분양(초대코드) → 지상에서 키우기·조작 학습(미니게임) → 레벨업 → 발사체 청약
   → 발사 시퀀스 → 궤도 진입 → 음영 지역 자동 수거 + 아케이드 모드 능동 수거
   → 인벤토리 합성·업그레이드 → 더 잘 줍는 줍스 → (반복) + 친구 초대
```

두 가지 게임 성격이 결합된다:
- **방치형(다마고치)**: 줍스를 분양·육성하고, 궤도에서 자동으로 쓰레기를 수거한다.
- **아케이드**: 음영 지역이 아닐 때 직접 조작해 우주 쓰레기를 수거하는 실시간 플레이.

## 대상 플랫폼 / 제약

- **모바일 세로 화면 전용** 웹 게임. 가로/데스크톱은 1차 대상 아님.
- **PWA** — 홈 화면 설치, 세로 고정, 버전업 대응.
- **10개 주요 언어** 지원, 설정에서 변경 가능, **폴백은 영어**.

## 디자인 방향 — 카세트퓨처리즘(Cassette Futurism)

1970~80년대가 상상한 미래의 미감. 아날로그 계기판, CRT 스캔라인, 도트/세븐세그먼트 디스플레이, 두꺼운 베젤, 물리 버튼과 토글, 형광 그린/앰버 모노크롬 + 절제된 네온. "낡았지만 미래적인" 우주 관제 콘솔 느낌을 UI 전반에 적용한다. → 상세: [디자인 요청 브리프](../design/design-brief.md) · [디자인 토큰 초안](../design/design-tokens.md)

## 주요 화면 (이슈의 4개 화면)

1. **첫 화면** — 궤도를 도는 줍스 100개, 총 청소량·%, 랭킹. 로그인 없이 볼 수 있음. → 첫 구현 대상(M1)
2. **두 번째 화면** — 분양 후 설정, 지상 미니게임, 발사체 청약
3. **세 번째 화면** — 발사 카운트다운·중계, 리플레이·공유
4. **네 번째 화면** — 우주의 내 줍스(지도·상태), 음영 자동 수거, 초대 공유, 아케이드 모드
